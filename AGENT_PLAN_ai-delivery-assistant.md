Лечение — свежий том + повторная миграция из внешнего источника, а не fsck на живом vhdx (в нём же данные inventory).
- 2026-10-21 — Скриншоты SPA: Chrome `--headless=new --virtual-time-budget=15000 --window-size=1440,900` на `127.0.0.1` (не `localhost`); перед съёмкой сначала проверить стек (`/api/health`), иначе снимутся страницы ошибок Chrome.
- 2026-10-22 — «Пропавший» блокер multipart: падение 12 тестов (2026-10-21) было env-состоянием системного Python (python-multipart доустановился в процессе диагностики), код проекта не виноват; свежий прогон 2026-10-22 — 12 passed без изменений кода. Вывод: перед отладкой «сломанных» тестов перезапускать их в свежем состоянии.
- 2026-10-26 — Docker-on-USB ревери-плейбук (проверен на инциденте №4): EBADMSG при bootstrap = порча; лестница: 1) chkdsk D: /f — всегда первым (NTFS-слой, «orphan file record» — чинится за секунды); 2) если не помогло — стоп DD + `wsl --mount --vhd D:\Docker\wsl\disk\docker_data.vhdx --bare` (НЕ требует admin!), опознать диск: `wsl -d Ubuntu -u root df -h /` (корень Ubuntu — НЕ трогать!) + blkid; 3) `e2fsck -n -f /dev/sdX` — оценка read-only: если только orphan-inode/чексуммы БЕЗ I/O-ошибок — блоки целы; 4) `e2fsck -y -f` — чинит; 5) `wsl --unmount` → старт Docker Desktop → engine ~3 мин. Уточнение к 2026-10-21: «не fsck» относилось к ЖИВОМУ vhdx при работающем Docker; офлайн-fsck (docker стоп + wsl --shutdown) — безопасен и спасает данные. Плюс: пересоздание docker-desktop-дистрибутива (wsl --unregister docker-desktop) безопасно для диска данных, но при ext4-порче НЕ помогает.
- 2026-10-26 — Хвост инцидента №4: containerd в VM docker-desktop ушёл в read-only («write meta.db: read-only file system») через ~12ч после e2fsck-ревери; D: при этом писался нормально. Лечение: чистый рестарт VM (kill DD → wsl --shutdown → старт DD) — БЕЗ пересоздания дистрибутива, build прошёл сразу. Вывод: при RO-ошибках внутри VM после ревери — чистый рестарт до радикальных шагов. Recharts-урок: у BarChart layout="vertical" НЕ удалять YAxis (ось категорий驱动 раскладку — без неё рендерятся 1-2 бара) — скрывать через hide.
